UPIC Studio is a mobile composition instrument built on the musical ideas of Iannis Xenakis.

Draw freehand UPIC arcs, generate scores with sieves, Markov chains, stochastic clouds, or game-theoretic strategy, and hear the page immediately through a GENDYN-powered synthesis engine. The same header-only C++ algorithms used by the Xenakis Tools desktop and VST3 editions run natively on Android.

FEATURES

• UPIC score canvas — draw, select, and erase arcs; pinch to zoom and drag to pan.
• Arc browser — find, select, deselect, or delete any arc from a list.
• Precise view ranges — type exact bottom/top frequencies and start/time span, or fit the whole page. New pages span roughly 33 Hz to 20 kHz.
• Program library — load eight built-in pages, save your own programs, and resume your current page automatically.
• Four generators — Sieve, Markov, Cloud, and Strategy pages with adjustable range, seed, density, and length.
• Dynamic stochastic synthesis — shape GENDYN segments, distributions, amplitude steps, and barriers.
• Live GENDYN notes — hold the on-screen keys to audition stochastic voices.
• Immediate playback — looping transport, speed control, and master gain.
• Landscape-only workspace — every tool, transport action, zoom control, and file action shares a single compact top line, leaving almost the entire screen for the score. A collapsible side panel holds the deeper controls.
• Portable scores — open and save .xenpage files through Android's document picker. The format is shared with the desktop and VST3 editions.

NO ACCOUNTS. NO ADS. NO TRACKING.

UPIC Studio works offline. It does not request network access, microphone access, or any runtime permission. Scores are read and written only when you choose a file.

UPIC refers to the historical CEMAMu graphical composition system. This is an independent project, not affiliated with or endorsed by the Xenakis estate or CEMAMu.
