Xenakis UPIC - installation

VST3
----
Linux:   copy "Xenakis UPIC.vst3" into ~/.vst3/
Windows: copy "Xenakis UPIC.vst3" into C:\Program Files\Common Files\VST3\
macOS:   copy "Xenakis UPIC.vst3" into ~/Library/Audio/Plug-Ins/VST3/

Rescan plugins in your host (YAWN, Bitwig, Reaper, ...), add "Xenakis UPIC" to
an instrument track, open the editor, press Open, and choose a .xenpage file
from presets/. You can also draw a new page and press Play.

Standalone
----------
Linux:   ./Xenakis UPIC Studio [preset.xenpage]
Windows: "Xenakis UPIC Studio.exe" [preset.xenpage]
macOS:   open "Xenakis UPIC Studio.app"
         First launch: right-click the app and choose Open (the build is
         ad-hoc signed, not notarized).

The Windows build uses the Microsoft Visual C++ 2015-2022 runtime (normally
present on Windows 10/11; install the x64 redistributable if the app or plugin
does not start).

Quick controls
--------------
- Draw: drag from the start of an arc to its end.
- Erase / Select: choose the tool in the toolbar.
- Play scans the page; Loop, Reverse and Speed are in the transport.
- The side tabs generate pages with Sieve, Markov, Cloud, Game and GENDYN.
- Ctrl/Cmd + mouse wheel zooms; mouse wheel scrolls.
